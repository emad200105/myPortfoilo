Layout-Consistency Loss: Free Geometric Supervision for Document Image Dewarping

Md Abu Hasnat, Md Atiqur Rahman Rohid, Md Sakib Uddin Niloy, Kazi Jaberul Islam Nafi, MD. Siamul Islam Apurbo, Md Juwel Mia, Muhammad Nomani Kabir

Interactive Mesh · PubLayNet Region Box → Unbent Text Lines Rectified: 88% · CER: 28.8%
-6.7% Layout Distortion
30.4% → 28.6% Tesseract CER
6.45M U-Net · 141,869 Warps
±0.004 DocUNet MS-SSIM Parity
  • Proposed a training loss leveraging free region boxes from layout datasets (PubLayNet) to penalise text-line bending rather than rigid shifts — requiring no OCR, line detector, or flow inversion.
  • Trained a 6.45M-parameter U-Net flow regressor (PyTorch, Kaggle GPUs) on 141,869 synthetic warps; single-variable ablation cut layout distortion by 6.7% at unchanged flow error and reduced character error rate from 30.4% to 28.6%.
  • Built a reproducible DocUNet benchmark evaluation (Octave/MATLAB, pinned Tesseract) matching published input scores within 0.004 MS-SSIM.
